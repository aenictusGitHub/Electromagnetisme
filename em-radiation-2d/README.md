# EM radiation 2D

Interactive two-dimensional electromagnetic-radiation simulator for the
`Electromagnetisme` course repository.

[Open the hosted simulator](https://radiation-2d-simulator.jmartin741572.chatgpt.site)

## Run locally

```bash
pnpm install
pnpm dev
```
